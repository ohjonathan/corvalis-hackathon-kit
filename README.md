# Hands-on hackathon: your client's SAP program is in trouble

McKinsey × Stanza · GE-O Tech & AI Knowledge Day · Lisbon · 23 October 2026

**Get the kit.** On this page, click **Code > Download ZIP** and unzip it (no GitHub account needed),
or `git clone https://github.com/ohjonathan/stanza-lisboa-hackathon-kit`. Then open **START_HERE.html** in your browser for the full task card.

The short version:

**The brief.** Imagine your client: their SAP program is facing challenges, and you need to create a view and an artifact to communicate with your executive clients. What would you build?

**The situation.** Corvalis Medical Devices (fictional) is replacing Oracle E-Business Suite
with SAP S/4HANA in Project Keystone. The Design gate is slipping, and the steering committee
meets on 28 Oct. The program office's dashboard is `single_source_of_now.html` (double-click it).
All its data is at the top of that file.

**Your task.** With Cursor, build an artifact your client's executives would act on: a
steering-committee one-pager, a decision memo, a "what changed this week" email, a risk heat
map, a CFO view of value at risk, or your own idea. Every number traces to the data.

**How to start.**
1. In Cursor: File > Open Folder... and choose this folder.
2. Open the AI chat (Cmd+L on Mac, Ctrl+L on Windows). Agent mode is usually the default.
3. Open `PROMPT.md`, edit the Audience, Artifact and File name lines if you picked another
   direction, then copy all of it into the chat and send.
   (Or use a Copy prompt button in `START_HERE.html`.)
4. When the agent has written your file: in Cursor's file list, right-click it >
   Reveal in Finder (Mac) or Reveal in File Explorer (Windows), then double-click it.

**Timing (Lisbon, Fri 23 Oct).** Create 11:00 · review 11:10 · build or fix 11:17 · check 11:35 · share-out 11:40 (60 seconds per table) · close 11:52.

**Rules.** Synthetic data only. Never paste client or confidential data into any AI tool.
No sign-ins beyond your own Cursor. Every number traces to the data.

**If Cursor won't start.** Share the table's working laptop, ask a Stanza host for a loaner,
or paste `paste-in/PASTE_IN.md` into any AI chat your firm allows.
