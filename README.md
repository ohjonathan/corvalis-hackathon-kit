# Hands-on hackathon: find what the SOP doesn't say

McKinsey × Stanza · GE-O Tech & AI Knowledge Day · Lisbon · 23 October 2026

**Get the kit.** On this page, click **Code > Download ZIP** and unzip it (no GitHub account needed),
or `git clone https://github.com/ohjonathan/corvalis-hackathon-kit`. Then open **START_HERE.html** in your browser for the full task card.

The short version:

**The situation.** Corvalis Medical Devices (fictional) runs order-to-cash on Oracle
E-Business Suite 12.1.3 and is moving to SAP S/4HANA. Discovery collected six documents
about one process, Standard Sales Order Entry. They are in `data/`.

**Your task.** With Cursor, build `as_is.html`: how the process really runs, every gap
between the SOP and reality, who owns each gap, the risk, and the S/4HANA design question
it raises. Every claim cites a file.

**How to start.**
1. In Cursor: File > Open Folder... and choose this folder.
2. Open the AI chat (Cmd+L on Mac, Ctrl+L on Windows). Agent mode is usually the default.
3. Open `PROMPT.md`, select all of it, copy, paste it into the chat and send.
   (Or use the Copy prompt button in `START_HERE.html`.)
4. When the agent has written `as_is.html`: in Cursor's file list, right-click it >
   Reveal in Finder (Mac) or Reveal in File Explorer (Windows), then double-click it.

**Timing.** Build 7-27 min · review every citation 27-32 · share-out 32-40 (60 seconds per table).

**Rules.** Synthetic data only. Never paste client or confidential data into any AI tool.
Every claim cites a file. "Unconfirmed" beats invented.

**If Cursor won't start.** Share the table's working laptop, ask a Stanza host for a loaner,
or paste `paste-in/ALL_SOURCES.md` and `PROMPT.md` into any AI chat your firm allows.
