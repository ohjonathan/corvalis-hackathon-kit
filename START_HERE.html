McKinsey × Stanza · GE-O Tech & AI Knowledge Day · Lisbon · 23 October 2026

Your client's SAP program is in trouble. What would you build?

Corvalis Medical Devices (fictional) is replacing Oracle E-Business Suite with SAP S/4HANA. The Design gate is slipping, and the steering committee meets on 28 Oct. The program office has a dashboard. Your table builds what the executives will act on.

1The brief

"Imagine your client: their SAP program is facing challenges, and you need to create a view and an artifact to communicate with your executive clients. What would you build?"

2What's in the kit

  • single_source_of_now.htmlThe program office's dashboard: Executive, Program management, Team lead. Double-click it first.
  • data/program.jsAll the program data: milestones, teams, risks, issues, decisions, actions, budget, value case, this week's changes. Every record has an ID. Change it and reload to change the story.
  • PROMPT.mdThe starting prompt for Cursor's agent.
  • AGENTS.mdThe rules Cursor's agent follows in this folder.

3Pick a direction (or bring your own)

Steering-committee one-pager
For the steering committee, chaired by the CFO. File: steerco_onepager.html
Status in one line, the two or three things that matter, and the decision you need on 28 Oct.

Our client is Corvalis Medical Devices (fictional). Its SAP S/4HANA program, Project Keystone, is in trouble, and the steering committee meets on 28 Oct 2026.

Audience: the steering committee, chaired by the CFO
Artifact: a one-page steering-committee view built around one clear decision ask
File name: steerco_onepager.html

1. Read AGENTS.md, then all of data/program.js. Look at single_source_of_now.html: it is the dashboard the program office uses today.
2. In the chat, give me five lines first: the so-what in one sentence, the decision you would ask for, and the three facts that support it, each with its record ID.
3. Then build the artifact as one self-contained HTML file in this folder, under the file name above:
   - load the data with <script src="data/program.js"></script> and take every number from it;
   - lead with the so-what and the decision ask, then the evidence;
   - put the record ID next to every fact, like [M2], [D-02], [R-07], [budget], [V-03], [team OTC];
   - label anything you calculate or judge as "inference" and show the arithmetic;
   - write for a busy executive: plain words, short sentences, no unexplained acronyms;
   - no external libraries, fonts or network calls. It must open by double-click.
4. When it is done, tell me the two questions this audience is most likely to push back with.

EvalsWhat good looks likeSet before you build, below. Judged on the so-what, the decision ask, the evidence, and fit for an executive.

6Table roles (5-6 people)

DriverHands on Cursor. Types what the table decides.
NavigatorsRead the data and the draft, suggest the next prompt. One plays the executive and pushes back.
SkepticTraces every number to its record in the data. Inference stays labeled.
PresenterGives the 60-second share-out.

7Start in Cursor

  1. Download the kit from github.com/ohjonathan/stanza-lisboa-hackathon-kit (Code > Download ZIP, no GitHub account needed) and unzip it. A USB copy is at your table.
  2. Double-click single_source_of_now.html to see the dashboard.
  3. In Cursor: File > Open Folder… and choose the unzipped kit folder.
  4. Open the AI chat (Cmd+L on Mac, Ctrl+L on Windows). Agent mode is usually the default.
  5. Paste the prompt for your direction and send it. Approve the agent's file changes when it asks.
  6. Keep improving it: "make the ask the first line", "what would the CFO push back on?", "what does waiting cost?".

9Rules

  • Corvalis Medical Devices is fictional. All data in this kit is synthetic.
  • Use only this kit's data. Never paste client or confidential data into any AI tool.
  • No sign-ins needed beyond your own Cursor.
  • Every number traces to a record in data/program.js. "Not in the data" beats invented.

10If Cursor won't start

  1. One working Cursor per table is enough: build on the driver's laptop.
  2. Ask a Stanza host for a loaner laptop.
  3. Paste-in mode: copy all of paste-in/PASTE_IN.md into any AI chat your firm allows. Save the HTML it returns as a file ending in .html and double-click it.
  4. Still stuck: play the executive or the skeptic for a neighboring table.

11Open your result

In Cursor's file list, right-click your file > Reveal in Finder (Mac) or Reveal in File Explorer (Windows), then double-click it. It opens in your browser, with no server and no internet needed. To show it at share-out, press F11 (Windows) or Ctrl+Cmd+F (Mac) for full screen.

12Share-out (60 seconds)

Show the artifact. Say the so-what, the decision you ask for, and one number with its source. Judged on the so-what (clear in ten seconds?), the decision ask (who decides what, by when?), the evidence (does every number trace to the data?) and fit for an executive (would they read it and act?).
